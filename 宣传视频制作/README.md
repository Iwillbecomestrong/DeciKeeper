# 决定守护首发内容稿件 (docs/content)

> **定位**：本目录收录决定守护 B 站首发内容的口播稿、节点排期与字数统计工具。
> 本文件同时作为进入 `docs/content/` 的 **Local README Gate**。

---

## 1. 文件一览

| 文件 | 用途 |
|:---|:---|
| `narration_count.py` | 口播字数与时长统计工具（同时是三份稿件的唯一真相源） |
| `video1_narration.md` | 视频 1 定稿旁白（含节点时间码） |
| `video2_outline.md` | 视频 2 节点排期与录屏分段表 |
| `video3_outline.md` | 视频 3（AI 二次创作）结构草案 |

---

## 2. 使用方式

```powershell
# 统计全部稿件
python docs/content/narration_count.py

# 只统计指定稿件（video1 / video2 / short）
python docs/content/narration_count.py video1
```

改稿后**必须重跑本脚本**，不要凭感觉判断时长。

---

## 3. 计数口径与语速基准

- **计数口径**：汉字按个计 1；连续英文字母/数字串按词计 1；标点与空白不计。
  口径与最初母稿统计保持一致，**不得更改**，否则历次数据不可比。
- **语速基准**：中文口播 220–250 字/分钟，本系列统一按 **230 字/分钟**排期。

## 4. 三条视频的漏斗关系

**认识 → 上手 → 参与**，每条自带下一步动作。

| 视频 | 标题 | 时长 | 字数 |
|:---:|---|:---:|:---:|
| 1 | 我做了一个自己每天都在用的软件，现在把它开源了 | ~8 分 | ~1900 |
| 2 | 决定守护使用指南：如何建立自己的手机边界 | ~10 分 | ~1035（口播部分） |
| 3 | 不会 Android 开发，也能用 AI 修改开源 App？ | 5–7 分 | 待定 |

视频 2 的成片时长 = 口播 270s + 操作演示 300s，详列见 `video2_outline.md`。

---

## 5. 维护约定

1. 稿件正文一律写在 `narration_count.py` 的字典里，**不要另建纯文本稿**，
   避免脚本与稿件脱节。
2. 任何结构性调整（合并/拆分节点、增删段落）完成后立即重跑统计，
   并同步更新对应 `*_outline.md` 中的时间码。
3. 本目录属内容资产，不参与 Gradle 构建，也不影响 `scripts/` 的单元测试。
