# 决定守护 DeciKeeper 权限与数据边界说明

> **严格单机**：决定守护不提供账号、云同步、远程控制或网络业务；规则判断、扫码输入和题库处理均在设备本地完成。扫码使用随 APK 打包的 Google ML Kit 条形码模型，不是云端识别；最终 APK 不声明 `INTERNET` 或 `ACCESS_NETWORK_STATE` 权限，应用不会发起普通网络请求或上传用户数据。

> 说明：这里的“单机”是本项目对应用业务和最终 APK 的硬边界。Google ML Kit 的通用厂商条款属于依赖声明事项，不改变本项目不联网、不上传、不提供云服务的产品规则；详见仓库第三方声明。

应用使用以下权限或系统设置来实现核心功能。不同手机品牌的名称和设置路径可能略有差异；**文中提到的系统设置如果在你的手机上不存在，则无需处理**。

---

## 一、基础运行（日常拦截与常驻保活）

初次使用时，按照首页引导开启以下 4 项基础配置，即可确保日常勿扰拦截、时间窗以及挑战闹钟正常工作：

1. **悬浮窗权限**：用于在受限应用启动时显示拦截提醒，以及在闹钟触发时展示挑战界面。
2. **通知权限**：用于发送定时提醒、闹钟提醒与前台常驻服务状态。
3. **自启动（系统设置）**：部分手机提供的系统设置，用于允许应用在手机开机或重启后自动恢复运行。
4. **后台耗电管理（系统设置）**：部分手机提供的系统设置（如设为“允许后台高耗电”或“无限制”），用于减少系统省电策略对应用后台运行的限制，降低闹钟与拦截服务被系统清理的风险。

> ℹ️ *自启动和后台耗电管理是手机厂商提供的系统设置，并非数据权限，不用于收集或上传任何数据。*

---

## 二、挑战闹钟（防漏响与起床核验）

1. **睡眠待机优化（系统设置）**：
   - **作用**：部分手机在夜间深睡待机时会深度冻结后台进程，可能导致闹钟延迟或漏响。关闭相关睡眠待机 / 后台省电限制可以降低这类风险，但不能保证所有品牌、所有系统版本下绝对准时。
   - **注意**：如果教程路径找不到，先在系统设置中搜索；如果系统本身没有该选项，无需继续寻找，可直接在引导中确认或跳过。
2. **相机权限**：
   - 仅在用户主动选择并使用「扫码挑战」时请求，用于识别镜头所对准的二维码内容；二维码在设备本地瞬时比对，**绝不拍摄、录制、保存或上传任何图像**。

## 三、时间规则（应用使用识别）

1. **使用情况访问权限**：
   - 用于在本地识别当前前台正在运行的应用包名，从而判断是否命中勿扰时段或应用时间窗锁；所有判断均在手机本地实时完成，绝不上报或用于任何用户画像。
2. **读取应用列表**：
   - 用于在配置时间规则时向你展示手机中已安装的应用，方便你勾选受限制的目标；应用列表数据仅保存在本地。

---

## 四、增强能力（高级防绕过，按需开启）

以下为可选的高阶保护能力。**新手第一次使用时无需开启**，可在熟悉基础功能后再按需选用：

1. **无障碍服务**：
   - 决定守护权限等级最高的增强保护能力。用于实现防卸载、防关闭关键权限、系统设置页拦截等高级防护，增加冲动拆防线的摩擦成本。
   - 开启「开发者选项拦截」后，进入系统「开发者选项」页（USB 调试、无线调试所在页面）会被退回桌面；关闭同样遵循“明日生效”规则。
   - 开启「安装拦截」后，在系统安装器里安装或更新决定守护本身的页面会被退回桌面；安装其他应用不受影响。需要更新时先关闭该保护，关闭同样遵循“明日生效”规则。
   - 界面文字识别限定在桌面、设置、应用商店、手机管家、安装卸载工具及已适配的系统保护页面。普通第三方应用仅识别包名、页面类名和窗口可见性，用于时间规则，不读取聊天或页面正文；不进行截屏或录屏。这不保证消除手机系统的无障碍安全提醒。
   - *悬浮窗与时间规则是独立的系统机制，并不单点依赖无障碍；未开启无障碍时仅高级防护降级，不影响基础的勿扰拦截与闹钟响铃。*
2. **关联启动（系统设置）**：
   - 无障碍服务的配套系统设置。部分手机在清理内存时会误停无障碍服务；允许关联启动有助于系统在服务异常中断后自动重新拉起。
3. **锁屏显示**：
   - 仅在使用「闹钟防关机」等高强保护时使用，确保闹钟提醒和挑战界面在锁屏状态下能正常覆盖展示。
4. **设备管理器（可选冗余）**：
   - OPPO/ColorOS 已有实测环境可作为防卸载冗余；vivo/iQOO 不默认推荐，其他品牌与 ROM 未验证。
   - 激活必须以系统 `isAdminActive` 查询为准。返回系统授权页但未点击激活时，App 不显示“已激活”。
   - 保护开关关闭后，系统设备管理器可能仍保持激活；待关闭期间仍按保护状态工作，状态到期后 App 会提供前往系统设置手动取消激活的入口。用户最终可以正常取消激活并卸载。

## 五、数据存储、导出与隐私归属

- **纯本地私有沙箱**：应用的规则、额度流水和诊断日志均存储在设备本地私有目录（`/data/data/com.decikeeper.app/`），应用卸载时该目录由系统清除；
- **内部故障防损快照**：应用平时在私有沙箱内维护隐藏的当前版与上一版快照，仅用于防范运行期文件损坏，不向公共目录自动写入，卸载时会随应用被系统一同清除；
- **手动备份与恢复**：需要卸载重装、换机或长期保存时，请在【设置 → 数据备份与恢复】中主动导出备份文件；重新安装后，从备份文件中手动选择导入。损坏或格式非法的条目会在写入前整体拒绝，避免覆盖已有配置。
- **系统备份与 App 备份是两条链**：Android 系统云备份/设备迁移是否包含本 App 数据，取决于系统和厂商策略；它们不替代用户的手动导出文件。
- **权限可撤销，但保护可能延期关闭**：你可以在系统设置中撤销权限；对防卸载、防关权限等保护开关，正常保护期的关闭申请可能按“明日生效”规则处理，期间仍继续保护。撤销无障碍后功能会降级或进入协同关闭流程，不代表其他模块全部失效。
