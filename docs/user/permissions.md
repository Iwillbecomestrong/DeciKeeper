## 1. 数据方式一句话总结

决定守护是一款单机软件，不收集任何数据。闹钟设置、挑战配置、规则配置和运行日志均存储在用户设备本地，并支持用户主动导出日志和设置；导出后的文件由用户自行保存或分享。

本说明适用于 v0.2.0 单机内测版。应用不会创建账号，也不会将数据上传到服务器。

## 2. 权限与系统设置清单

应用使用以下权限或系统设置实现核心功能。不同手机品牌的名称和设置路径可能不同；文中提到的系统设置如果在你的手机上不存在，则无需处理。

### 2.1 基础运行

1. **悬浮窗权限**：用于显示必要的提醒和挑战界面。
2. **通知权限**：用于发送闹钟提醒和必要通知。
3. **自启动**：部分手机提供的系统设置，用于允许应用在手机重启后自动恢复运行。
4. **后台耗电管理**：部分手机提供的系统设置，用于减少系统省电策略对应用后台运行的限制，降低闹钟服务被系统停止的风险。

**自启动和后台耗电管理不是数据权限，也不用于收集或上传用户数据。**

### 2.2 挑战闹钟

1. **睡眠待机优化**：这是部分手机提供的系统设置，可能显示为“睡眠模式”等类似名称。关闭后，可以降低手机在夜间锁屏待机时冻结应用，导致闹钟漏响或延迟的风险。
2. **相机权限**：仅在用户主动选择扫码挑战时使用，用于读取镜头指向的二维码；二维码内容在本地处理。

### 2.3 规则保护

1. **使用情况访问权限**：用于识别应用的前台使用状态，以实现应用时间窗和相关规则；数据仅在设备本地处理。
2. **应用列表**：用于让用户选择需要应用规则保护的应用。选择结果和相关配置均保存在用户设备本地。

### 2.4 增强能力

1. **无障碍服务**：用于实现规则保护功能，帮助减少用户绕过闹钟限制的行为。
2. **关联启动**：这是无障碍服务的配套系统设置，不是独立的数据权限。部分手机会在后台清理时停止无障碍服务；开启关联启动，可以帮助系统在服务被停止后自动恢复，降低无障碍服务被误杀后无法重新拉起的风险。若未开启，规则保护和相关能力可能在后台清理或系统重启后暂时失效，需要回到应用重新检查。
3. **锁屏显示**：仅在用户使用闹钟防关机功能时，用于让闹钟提醒和挑战界面在锁屏状态下正常显示。

## 3. 第一次使用的推荐开启顺序

如果你只是想先试试看决定守护是否适合自己，**不需要一上来就开启无障碍**。

更推荐的顺序是：

1. 先用首页 5 项基础权限体验基础功能；
2. 确认规则、锁屏和后台运行在自己的手机上稳定；
3. 确实希望增加绕过成本时，再开启无障碍以及依托无障碍的加强约束功能。

**无障碍是决定守护权限等级最高、能力最强的一项权限。** 它主要用于更强的系统级保护和加强约束，例如防卸载、防关关键权限、系统设置页拦截、隐私空间等。

需要说明的是：悬浮窗、使用情况访问等是独立的 Android 系统权限，并不是依托无障碍才能存在。基础的前台识别、锁屏覆盖和拦截链路并不单点依赖无障碍；无障碍不可用时，应当是**部分能力降级**，而不是“所有功能都失效”。

第一次的完整上手流程见 [getting-started.md](getting-started.md)。

## 4. 权限被拒绝或失效时会怎样

- 用户可以在系统设置中查看或撤销上述权限。**拒绝某项权限可能导致对应功能无法使用，但不影响其他无需该权限的功能。**
- 关联启动未开启时，规则保护和相关能力可能在后台清理或系统重启后暂时失效，需要回到应用重新检查。
- 闹钟触发时如果悬浮窗权限被系统撤销，应用不会改用页面版挑战，也不会因继续添加悬浮窗而闪退；本次响铃会提示缺少悬浮窗权限并结束，重新开启权限后再使用闹钟。
- 如果无障碍看起来仍显示开启、但实际功能失效，可以尝试关闭后重新开启，并检查后台限制。
- 系统大版本升级后建议重新检查权限；ROM 更新后建议重新测试关键拦截。

## 5. 数据存储、导出与隐私边界

- **存储位置**：闹钟设置、挑战配置、规则配置和运行日志均存储在用户设备本地。
- **导出**：支持用户主动导出日志和设置；导出后的文件由用户自行保存或分享。
- **账号与服务器**：应用不会创建账号，也不会将数据上传到服务器。
- **本地处理**：使用情况访问用于识别应用前台使用状态，数据仅在设备本地处理；扫码挑战读取的二维码内容同样在本地处理。
- **备份与恢复**：备份可以恢复配置和本地业务数据，但 Android 系统权限通常需要在新设备或重装后重新授权。相关操作建议见 [guide.md](guide.md) 的「备份、导入和旧版迁移」。
- **未来变化**：本说明面向当前单机内测版，不构成应用商店运营阶段的完整隐私政策。若未来增加账号、云同步、第三方服务或其他数据处理方式，将在相应版本中单独说明。
