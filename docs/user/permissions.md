# 决定守护 DeciKeeper 权限与数据边界说明

> **单机无网，隐私安全**：决定守护是一款纯单机软件，没有任何联网权限，不收集任何用户隐私。闹钟设置、挑战配置、规则数据和运行日志均存储在你的设备本地。

---

## 1. 推荐开启顺序

如果你是第一次使用决定守护，**不需要一上来就开启无障碍**。

更稳妥、自然的开启顺序是：

1. **先开 4 项基础权限体验**：
   - 悬浮窗权限
   - 通知权限
   - 后台耗电管理
   - 自启动权限
   先用这 4 项基础权限体验日常的勿扰拦截、时间窗以及挑战闹钟，确认基础运行在自己的手机上稳定；
2. **需要加强防线时，再开启无障碍**：
   - **无障碍是决定守护权限等级最高、能力最强的一项权限**；
   - 它主要用于防卸载、防关关键权限、系统设置页拦截等高级防护；
   - 悬浮窗、使用情况访问等是独立的系统权限，并不单点依赖无障碍。无障碍不可用时属于部分高级保护降级，并不影响基础的规则拦截与响铃。

---

## 2. 权限失效与被杀排查

不同品牌手机的系统省电和后台查杀策略各有不同，日常使用中如果遇到功能异常，可对照排查：

- **通知或闹钟不响、响铃延迟**：
  - 检查 **后台耗电管理** 是否设为“无限制”或“允许后台高耗电”；
  - 检查系统设置中是否有“睡眠待机优化 / 夜间省电模式”，建议关闭该选项，防止夜间锁屏待机时系统冻结后台闹钟服务；
- **规则保护或无障碍失效**：
  - 部分厂商在后台清理时会误停无障碍服务。检查是否开启了 **自启动** 与 **关联启动**；
  - 若系统显示无障碍已开启但拦截无反应，尝试关闭后重新打开一次，即可重新激活系统无障碍通道；
- **锁屏或弹窗无法显示**：
  - 确认 **悬浮窗权限** 未被系统安全软件静默撤销；
  - 若使用闹钟防关机保护，需在系统应用设置中开启 **锁屏显示** 权限；
- **系统升级后排查**：
  - Android 大版本更新或手机系统升级后，系统可能会重置部分后台权限，建议在升级后重新打开应用检查关键权限状态。

## 3. 夜间防漏响与后台保活说明

在应用首次启动时，你通常已根据引导开启了 **「自启动」** 与基础权限。但在夜间，部分手机系统（特别是定制 Android 系统）拥有独立的 **深度睡眠 / 夜间省电机制**，可能会在凌晨彻底冷冻后台进程，导致早晨闹钟出现延迟或漏响。

为确保闹钟准时触发，请重点关注以下设置：

### 核心本质：两项关键配置
1. **电池策略设为「无限制 / 允许后台高耗电」**：确保系统在低电量或锁屏时不压制本应用；
2. **留意是否有独立的「睡眠待机优化」开关**：并非所有手机都有此开关，通常仅存在于 Vivo 和部分 OPPO 机型中。

### 各品牌系统设置指引

- **vivo / iQOO (OriginOS / FuntouchOS)** ⚠️ *需重点注意*：
  1. **关闭睡眠待机优化**：前往「设置 → 电池 → 更多设置（或电池健康与充电）」，找到 **「睡眠待机优化」** 并**关闭**（Vivo 系统在夜间静置时会极致冷冻后台，导致早晨闹钟无法拉起，关闭此项是准时响铃的关键）；
  2. **允许后台高耗电**：前往「设置 → 电池 → 后台耗电管理」，找到「决定守护」，选择 **「允许后台高耗电」**。

- **OPPO / 一加 / 真我 (ColorOS / RealmeUI)**：
  1. **关闭睡眠待机优化**：前往「设置 → 电池 → 高级设置」，若有 **「睡眠待机优化」** 开关，建议关闭；
  2. **允许完全后台行为**：前往「设置 → 应用 → 应用管理 → 决定守护 → 耗电管理」，勾选 **「允许完全后台行为」**。

- **小米 / 红米 (HyperOS / MIUI)**：
  - 小米没有单独的“睡眠待机优化”开关，直接长按桌面「决定守护」图标 → 应用信息 →「省电策略」，选择 **「无限制」**（默认的“智能省电”会在夜间锁屏限制后台）。

- **华为 / 荣耀 (HarmonyOS / MagicOS)**：
  - 华为没有单独的“睡眠待机优化”开关，前往「设置 → 电池 → 应用启动管理」，将「决定守护」改为 **「手动管理」**（确保允许自启动、允许后台活动）；并在「电池优化」中将决定守护设为“不允许”（即忽略优化）。

- **三星 (One UI) 与其他原生系统**：
  - 前往「设置 → 电池和设备维护 → 电池 → 背景使用限制」，将「决定守护」添加到 **「从不休眠应用程序」**；长按应用图标进入「应用信息 → 电池」，选择 **「不受限制」**。

## 4. 数据存储、导出与隐私

- **纯本地存储**：应用的所有业务数据仅保存在手机内部私有目录，绝无云端上传；
- **自主备份导出**：支持在【设置 → 数据备份与恢复】中主动导出配置与日志文件，导出后的文件由你全权管理与保存；
- **单机内测说明**：本说明面向当前单机版，不涉及账号体系或第三方商业 SDK。
