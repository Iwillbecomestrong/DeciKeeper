# 决定守护 DeciKeeper 权限与数据边界说明

> **单机无网，隐私安全**：决定守护是一款纯单机软件，没有任何联网权限，不收集任何用户隐私。闹钟设置、挑战配置、规则数据和运行日志均存储在你的设备本地。

---

## 1. 推荐开启顺序

如果你是第一次使用决定守护，**不需要一上来就开启无障碍**。

更稳妥、自然的开启顺序是：

1. **先开 4 项基础权限体验**：
   - 悬浮窗权限
   - 通知权限
   - 后台耗电管理
   - 自启动权限
   先用这 4 项基础权限体验日常的勿扰拦截、时间窗以及挑战闹钟，确认基础运行在自己的手机上稳定；
2. **需要加强防线时，再开启无障碍**：
   - **无障碍是决定守护权限等级最高、能力最强的一项权限**；
   - 它主要用于防卸载、防关关键权限、系统设置页拦截等高级防护；
   - 悬浮窗、使用情况访问等是独立的系统权限，并不单点依赖无障碍。无障碍不可用时属于部分高级保护降级，并不影响基础的规则拦截与响铃。

---

## 2. 权限失效与被杀排查

不同品牌手机的系统省电和后台查杀策略各有不同，日常使用中如果遇到功能异常，可对照排查：

- **通知或闹钟不响、响铃延迟**：
  - 检查 **后台耗电管理** 是否设为“无限制”或“允许后台高耗电”；
  - 检查系统设置中是否有“睡眠待机优化 / 夜间省电模式”，建议关闭该选项，防止夜间锁屏待机时系统冻结后台闹钟服务；
- **规则保护或无障碍失效**：
  - 部分厂商在后台清理时会误停无障碍服务。检查是否开启了 **自启动** 与 **关联启动**；
  - 若系统显示无障碍已开启但拦截无反应，尝试关闭后重新打开一次，即可重新激活系统无障碍通道；
- **锁屏或弹窗无法显示**：
  - 确认 **悬浮窗权限** 未被系统安全软件静默撤销；
  - 若使用闹钟防关机保护，需在系统应用设置中开启 **锁屏显示** 权限；
- **系统升级后排查**：
  - Android 大版本更新或手机系统升级后，系统可能会重置部分后台权限，建议在升级后重新打开应用检查关键权限状态。

---

## 3. 数据存储、导出与隐私

- **纯本地存储**：应用的所有业务数据仅保存在手机内部私有目录，绝无云端上传；
- **自主备份导出**：支持在【设置 → 数据备份与恢复】中主动导出配置与日志文件，导出后的文件由你全权管理与保存；
- **单机内测说明**：本说明面向当前单机版，不涉及账号体系或第三方商业 SDK。
