## 1. 决定守护是什么

决定守护是一款开源 Android 数字自律工具。它主要解决两件事：

1. **该停的时候停下来**：减少短视频、游戏、聊天、信息流等对学习、工作和睡眠的侵占。
2. **该起的时候起来**：让闹钟不只“响过”，而是推动你真正离开床铺。

决定守护不会替你决定应该做什么。它做的是：当你已经提前做出决定后，让冷静时的决定比下一刻的冲动多一点分量。

先记住几个正式名称，后面的说明都会用到：

| 概念 | 名称 |
| --- | --- |
| 产品 | 决定守护 / DeciKeeper |
| 手机限制模块 | **规则保护**（系统模块名）；用户入口页面叫**时间规则** |
| 闹钟模块 | **挑战闹钟**（用户入口）；系统模块名叫**起床系统** |
| 三个出口 | **休息 / 临时解锁 / 每周特权** |

## 2. 先理解“两把锁 + 三个出口”

决定守护最核心的手机使用逻辑可以概括成：

- 两把锁：**勿扰时段锁 / 应用时间窗锁**
- 三个出口：**休息 / 临时解锁 / 每周特权**

后面的所有配置基本都围绕这五个概念展开。

第一次使用只需要知道两件事：

- 两把锁决定“什么时候被拦”；
- 三个出口决定“临时真的有需要时，怎么按规则放行一小段时间”。

完整的配合关系、额度与冷却口径见 [guide.md](guide.md) 的「两把锁」「三个出口」「额度、结余、借用和冷却」三节。

## 3. 第一次先开基础权限，不需要先开启无障碍

如果你只是想先试试看决定守护是否适合自己，**不需要一上来就开启无障碍**。

### 3.1 先用基础权限体验

先按照首页的引导开启**首页的 5 项基础权限**，然后实际使用一段时间，确认：

- 前台应用识别正常；
- 锁屏覆盖层能正常出现；
- 勿扰时段和应用时间窗按预期生效；
- 后台运行基本稳定；
- 你的 ROM 没有频繁杀掉决定守护。

悬浮窗、使用情况访问等是独立的 Android 系统权限，并不是依托无障碍才能存在。

### 3.2 无障碍建议稍后再开

**无障碍是决定守护权限等级最高、能力最强的一项权限。** 它主要用于更强的系统级保护和加强约束，例如防卸载、防关关键权限、系统设置页拦截、隐私空间等。

### 3.3 更推荐的顺序

1. 先用首页 5 项基础权限体验基础功能；
2. 确认规则、锁屏和后台运行在自己的手机上稳定；
3. 确实希望增加绕过成本时，再开启无障碍以及依托无障碍的加强约束功能。

每一项权限分别用来做什么、拒绝后会怎样、数据存在哪里，见 [permissions.md](permissions.md)。

## 4. 创建第一个时间规则

### 4.1 先想清楚要限制什么

不要一开始就追求“最严”。更实用的做法是先挑出**最容易失控的 1–2 个应用**（例如短视频或游戏），先让规则跑通，再逐步扩展。

按应用性质分层配置的完整思路见 [guide.md](guide.md) 的「推荐配置思路」。

### 4.2 建立第一个勿扰时段

在**时间规则**页面里，最先要建立的是**勿扰时段**。勿扰时段回答的是：

> 一天中的哪些时间，命中限制范围的应用需要被拦截？

你可以创建多个勿扰时段，例如上午、下午、晚上、深夜，并为每个时段设置：

- 开始和结束时间；
- 生效星期；
- 该时段的限制应用；
- 休息时长；
- 可用次数等参数。

第一次建议只建一个时段，例如你的睡眠时间，并先把“限制应用”填得少一点。

### 4.3 需要时再加应用时间窗

**应用时间窗**回答的是：

> 某些高风险应用只允许在一天中的哪些时间使用？

常见做法是把游戏、短视频或其他容易失控的应用加入时间窗，例如只允许晚间某段时间使用。

如果某个应用同时受勿扰时段和应用时间窗限制，普通使用需要同时满足两边——这一点在第一次配置时最容易踩坑，详细例子见 [guide.md](guide.md) 的「两把锁是叠加关系」。

### 4.4 记住修改不会总是立刻生效

在正常保护期内：

- **加严限制：立即生效；**
- **放宽限制：下一刷新时刻生效。**

“下一刷新时刻”跟随你的业务日边界，**不是固定 00:00**。完整策略（宽严有别 / 统一延后）与例外见 [guide.md](guide.md) 的「规则修改与延期生效」。

## 5. 设置第一个挑战闹钟

### 5.1 先开启悬浮窗

闹钟挑战和锁界面都通过悬浮窗显示。第一次新增闹钟、保存闹钟、开启已有闹钟或点击「测试默认闹钟」时，若尚未开启悬浮窗权限，应用会提示你前往系统设置开启「显示在其他应用上层」。

### 5.2 选择第一关的挑战方式

你可以给闹钟配置多种挑战：

- **扫码**：扫描任意二维码即可通过。真正起作用的是二维码的物理摆放位置（如卫生间、客厅、洗手台）；
- **计算 / 诗词 / 单词 / 选词填空 / 自定义题库**：帮助半醒的大脑进入工作状态。

第一晚建议先用真实位置摆好二维码，再配置扫码挑战；每一种挑战类型的具体行为见 [guide.md](guide.md) 的「挑战闹钟」。

### 5.3 做一次完整测试

不同 ROM 的开机广播、后台启动和悬浮窗行为可能不同，因此**重要闹钟仍建议先在你的设备上做一次完整测试**：

1. 点一次「测试默认闹钟」，确认悬浮窗能正常弹出、挑战界面可用；
2. 设一个几分钟后的真实闹钟，确认第一关完成后会进入「完成后延迟」，以及延迟结束后才出现关闭按钮（单阶段）或进入第二关；
3. 如果打算用第二关，确认第二关的提醒设置符合预期。

完成后延迟、第二关、再响与闹钟恢复的完整说明见 [guide.md](guide.md) 的「挑战闹钟」。

## 6. 验证测试：确认它在你的手机上真的有效

第一次配置完成后，按下面的清单实测一遍（和「先用基础权限体验」是同一组检查项）：

- 前台应用识别正常；
- 锁屏覆盖层能正常出现；
- 勿扰时段和应用时间窗按预期生效；
- 后台运行基本稳定；
- 你的 ROM 没有频繁杀掉决定守护。

如果后续出现“权限看着是开着的，但功能没生效”的情况，常见处理是：

- 如果无障碍看起来仍显示开启、但实际功能失效，可以尝试关闭后重新开启，并检查后台限制；
- 系统大版本升级后重新检查权限；
- ROM 更新后重新测试关键拦截。

更多降级与恢复说明见 [permissions.md](permissions.md) 的「权限被拒绝或失效时会怎样」。

---

## 7. 决定守护不是“绝对无法绕过”的系统

Android ROM、隐私空间、系统设置页和厂商后台策略都很复杂。决定守护会持续补强实际发现的绕过路径，但不会对外承诺“绝对无法绕过”。

关闭关键保护通常会经过相应的延期流程，但用户最终必须能够按规则关闭保护并退出。相关说明见 [guide.md](guide.md) 的「防卸载和其他保护」。
