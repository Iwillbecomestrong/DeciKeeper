# 决定守护 DeciKeeper 新手指引

> **3 分钟快速上手**：开哪些权限、怎么建第一条规则、怎么设第一个挑战闹钟。

---

## 1. 核心概念（10 秒看懂）

- **两把锁**：
  - **勿扰时段**：一天中哪些时间限制使用手机。
  - **应用时间窗**：高风险应用（如游戏、短视频）只允许在什么时候打开。
- **三个出口**：
  - **临时解锁**：应急处理验证码、扫码、回急信（短时放行）。
  - **休息**：临时解除勿扰时段，但**不解除应用时间窗**。
  - **每周特权**：特殊情况（聚会、出行）的大出口。

---

## 2. 第一步：开启基础权限

首次使用**不需要先开启无障碍**。

先在首页引导中开启 **4 项基础权限**：
1. **悬浮窗权限**：显示锁屏与闹钟挑战；
2. **通知权限**：闹钟与状态提醒；
3. **后台耗电管理**：防止系统在后台杀掉应用；
4. **自启动权限**：保证手机重启后自动恢复守护。

> **无障碍是决定守护权限等级最高、能力最强的一项权限。** 建议先体验基础功能，确认规则稳定后，再按需开启无障碍及防卸载等加强保护。

---

## 3. 第二步：建立第一个时间规则

建议先挑 **1–2 个最容易失控的应用**（如短视频）开始：

1. 进入底部导航 **「时间规则」**；
2. **新建勿扰时段**：设置专注或睡眠时段（如 23:00–07:00），勾选受限应用；
3. **按需设置应用时间窗**：为游戏或娱乐应用指定允许使用的时段；
4. **修改生效规则**：正常保护期内，**加严立即生效，放宽下一刷新时刻生效**（下一刷新时刻跟随业务日边界，不是固定的 00:00）。

---

## 4. 第三步：设置第一个挑战闹钟

决定守护不是把闹钟做得更响，而是让关闭闹钟变成一次真实行动：

1. 进入底部导航 **「挑战闹钟」**；
2. **首推扫码挑战**：扫描任意二维码即可通过。把二维码贴在洗手台或客厅，真正起作用的是物理距离；
3. 也可选用计算、单词、诗词或自定义题库挑战；
4. **完成后缓冲**：第一关完成后进入轻柔倒计时缓冲，给洗漱留出时间，防止秒回床上刷手机；
5. 点击「测试默认闹钟」验证悬浮窗与答题是否正常。
