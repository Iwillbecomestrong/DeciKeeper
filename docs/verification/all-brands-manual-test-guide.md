## 一、通用 4 大极限破坏性测试（全机型必测）

无论使用什么牌子的手机，请测试人员使出浑身解数尝试“攻破”防线：

### 🎯 挑战 1：极限手速卸载（防卸载时效测试）
- **操作步骤**：
  1. 确保已在应用内开启「无障碍服务」；
  2. 在桌面上长按「决定守护」图标，点击弹出气泡中的「卸载」；
  3. **考验手速**：在系统弹出卸载确认弹窗的**同一毫秒**，凭肌肉记忆疯狂狂点屏幕确认卸载的位置！
- **合格标准**：无障碍服务以毫秒级速度自动将弹窗取消或退回桌面，**应用绝对没有被卸载**。

### 🎯 挑战 2：长待机夜间 Doze 唤醒（防漏闹钟测试）
- **操作步骤**：
  1. 在决定守护中新建一个挑战闹钟，设定为 **30 分钟 ~ 1 小时后**（或者睡前定明早闹钟）；
  2. 拔掉充电线，手机锁屏，**将手机平放在桌上完全不要移动、不要点亮屏幕**（让手机进入系统底层深度休眠 Doze / Super Freeze）；
  3. 闹钟时间到达时观察表现。
- **合格标准**：时间一到，手机**立即准时亮屏、播放闹钟铃声、弹出全屏挑战遮罩**；
- **翻车表现**：如果直到你手动按电源键点亮屏幕那一刻闹钟才“补响”，说明该机型的睡眠省电策略未配置成功。

### 🎯 挑战 3：多任务暴力一键清理（进程常驻与自愈测试）
- **操作步骤**：
  1. 从屏幕底部上滑呼出多任务卡片界面；
  2. 点击底部的「清除全部 / 扫把」按钮，或猛烈上滑划掉「决定守护」卡片；
  3. 清理后**立即**（不用等待）去桌面上尝试长按卸载，或者去打开被监管的时间规则黑名单应用。
- **合格标准**：无障碍服务没有死掉；通知栏的守护常驻前台通知依然存在（或在 3 秒内自动复活）。

### 🎯 挑战 4：花式多任务偷玩绕过（手势防绕过测试）
- **操作步骤**：
  1. 设定一条时间规则（当前时段为勿扰管制期，如微信/小红书被加入限制名单）；
  2. 打开该受限应用，此时界面被全屏黑色/主题色遮罩锁定；
  3. **尝试绕过手段**：
     - 尝试呼出系统的**侧边栏小窗 / 悬浮小窗 / 浮窗模式**打开该应用；
     - 尝试三指上滑或分屏手势进入**分屏多任务**模式；
     - 尝试通过锁屏界面的快捷入口或状态栏通知跳转进入该应用。
- **合格标准**：遮罩必须无死角覆盖或立即关闭该界面，无法通过小窗/分屏偷玩手机。

## 二、各大手机品牌专属测试核对清单

### 1. 小米 / 红米 (Xiaomi / Redmi) 专属检查
- [ ] **后台弹出界面权限**：在系统「设置 -> 应用设置 -> 应用管理 -> 决定守护 -> 权限管理」中，【后台弹出界面】必须为「允许」（此权限决定锁屏状态下能否弹出全屏挑战闹钟）。
- [ ] **省电策略**：必须设置为「无限制」（禁止选择“智能推荐”）。
- [ ] **应用自启动**：开启自启动开关。

### 2. 华为 / 荣耀 (Huawei / Honor) 专属检查
- [ ] **应用启动管理**：在系统「设置 -> 电池 -> 应用启动管理」中，找到决定守护，**关闭「自动管理」**，在弹出的窗口中必须**同时勾选三项**：
  - [x] 允许自启动
  - [x] 允许关联启动
  - [x] 允许后台活动
- [ ] **电池优化**：进入「设置 -> 应用和服务 -> 权限管理 -> 特殊访问权限 -> 电池优化」，设为「不允许」（即忽略电池优化）。

### 3. OPPO / 一加 / 真我 (OPPO / OnePlus / Realme) 专属检查
- [ ] **完全允许后台行为**：进入「设置 -> 电池 -> 应用耗电管理 -> 决定守护」，必须勾选【完全允许后台行为】。
- [ ] **关闭睡眠待机优化**：进入「设置 -> 电池 -> 高级设置/省电设置」，将【睡眠待机优化】开关**关闭**。
- [ ] **开机启动/自启动**：在应用详情中开启自启动。

### 4. Vivo / iQOO 专属检查
- [ ] **允许后台高耗电**：进入「设置 -> 电池 -> 后台高耗电」，开启「决定守护」开关。
- [ ] **关闭睡眠待机优化**：进入「设置 -> 电池」，关闭「睡眠待机优化」。
- [ ] **i管家自启动管理**：在 i管家或权限管理中，允许自启动。
