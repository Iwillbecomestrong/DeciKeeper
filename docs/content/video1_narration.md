## 三、为什么交给你（6:12 – 8:36 · 554 字）

**07 为什么开源**　`6:12 – 7:16`　·　248 字

最后我还是决定把知止开源，主要有三个原因。第一是透明。它会使用无障碍、防卸载、后台检测这些比较敏感的能力。我觉得这种软件，用户应该能看到它到底在干什么。不用相信我，可以直接看代码。说到防卸载，我想多讲一句：它防的不是卸载，是那一瞬间想卸载的冲动。你今天说想走，明天就能走。第二是可靠。Android 的厂商、系统版本、机型实在太多了，我一个人不可能测试完所有情况，也不可能发现所有绕过方法。第三是扩展。我能想到的规则、题型和用法终究有限，别人可能会有完全不一样，甚至更好的答案。代码在 GitHub 和 Gitee 上都能拿到，协议用的是 GPL。你可以自己看，也可以自己从源码构建一遍，再决定要不要信它。
