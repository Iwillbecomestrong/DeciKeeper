您可以在左侧手机模拟器中直接点击体验的真实流程：

👉 1. 点进「离床错题收藏夹」

对应 BookmarkActivity。诗词/单词/选词填空三Tab切换、按跳过次数排序、关键词搜索与时间过滤。

👉 2. 点击「测试响铃挑战」

模拟 window_alarm_overlay 离床答题，支持真实体验「收藏并跳过」，自动加入收藏夹！

👉 3. 点进「黑白名单选择页」

对应 AppSelectionActivity。支持黑名单/白名单模式切换、已安装应用勾选与保存生效。

👉 4. 点进「全局参数配置页」

对应 GlobalParamsActivity。修改每日基准时刻(08:00)、最大借用比例(50%)与双倍惩罚契约。

👉 5. 体验「6大无障碍约束守护」

点击无障碍、防卸载、防关权限、隐私空间拦截开关，真实触发知止“次日08:00生效”防冲动契约弹窗！

👉 6. 点击「+ 添加闹钟」弹窗

对应 dialog_alarm_edit.xml。选择唤醒时间、重复日、选择离床扫码挑战与防回马枪复核。
