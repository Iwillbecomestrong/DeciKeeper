# 统计逻辑加固计划

## 目标

修复统计模块中已确认的时长重复、范围口径、分类下钻、规则分桶与历史流水可靠性问题，同时保持现有业务规则不变。

## 阶段

- [x] 阶段 1：确认现状、边界与回归场景
- [x] 阶段 2：先写回归测试并确认测试能捕获问题
- [x] 阶段 3：实施最小实现修复
- [x] 阶段 4：全量验证、审查并产出报告

## 修复范围

1. UsageStats 前台 session 只在真实状态转换时结算，统一异常 session 上限并按分桶边界切分。
2. 自定义时间范围严格按时间交集统计，补齐跨午夜场景。
3. 分类详情按每个应用逐桶聚合，保证与主统计口径一致。
4. 规则保护按桶时间范围聚合，并读取真实待生效配置源。
5. 休息与规则最近记录遵守当前筛选范围。
6. 休息流水迁移到 SQLite，并保留旧数据迁移与备份兼容。
