# 统计逻辑加固调查记录

## 已确认根因

- `StatisticsRepository.getAppUsageStats` 在每个 UsageStats 事件前结算当前 session，即使该事件不是前台切换事件，会导致重复累计。
- 最后一个未收到结束事件的 session 使用 30 分钟上限，与普通 session 的 3 小时上限不一致。
- 应用分类详情使用全局比例缩放分桶，而不是按应用逐桶聚合。
- 退出统计总计按自然日读取，未与自定义的精确起止毫秒求交集；跨午夜小时图还只读取起始日期。
- 规则保护分桶只读取桶起始日期；待生效读取了历史 `pending_config_prefs`，并且返回值硬编码为 0。
- 休息流水仍是单个 SharedPreferences JSON；解析异常会让整批历史不可见。

## 约束

- 不改变额度、冷却、时间窗、题库或锁保护业务规则。
- 保留闹钟 SQLite 迁移及既有未提交修改。
- 所有修复先由回归测试锁定，再改生产代码。
