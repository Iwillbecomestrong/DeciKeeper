与第三方共享信息清单

版本：v0.1.0-2026-07-05
状态：占位合规文本，待法务 review

==============================================
概述
==============================================

  1. 本应用 **不在自有服务器上收集** 任何个人信息，因此也不存在"主动向第三方共享"的行为。
  2. 你与第三方之间可能发生的数据流转，仅在你 **主动** 触发下列功能时才会发生，且由你本人决定共享给哪个第三方。

==============================================
主动共享场景
==============================================

【S-01】使用"导出设置"
   - 触发条件：你主动点击"导出设置"并选择目标应用（微信、邮件、文件管理器等）。
   - 共享内容：你所选分类的本地配置（JSON 文件，不含其他个人信息）。
   - 接收方：你主动选择的目标应用 / 第三方。
   - 接收方处理：按该第三方自身隐私政策处理，本应用不承担责任。
   - 关闭方式：不再使用"导出设置"即可。

【S-02】使用"发送日志"
   - 触发条件：你主动点击"发送日志"并选择时间范围与目标应用。
   - 共享内容：近 N 天的诊断日志（崩溃堆栈、关键事件），可能包含设备型号、Android 版本等运行环境信息，但 **不包含可识别你身份的信息**。
   - 接收方：你主动选择的目标应用 / 第三方。
   - 接收方处理：按该第三方自身隐私政策处理。
   - 关闭方式：不再使用"发送日志"即可。

【S-03】使用"扫码导入设置"
   - 触发条件：你主动点击"扫码导入设置"并把镜头指向二维码。
   - 共享内容：无。本应用 **不上传** 摄像头数据；仅在本地解析二维码内容。
   - 接收方：无。
   - 关闭方式：不再使用"扫码导入设置"即可，或在系统设置中撤销 CAMERA 权限。

【S-04】清除应用数据 / 卸载
   - 触发条件：你主动清除应用数据或卸载本应用。
   - 共享内容：无。本应用 **不删除** 任何远程数据（因为没有）。
   - 接收方：无。
   - 关闭方式：—

==============================================
嵌入第三方 SDK 带来的共享
==============================================

  无。

  本应用当前不集成任何"会收集个人信息的第三方 SDK"，因此不存在 SDK 自动上传行为。

  详细清单见《第三方 SDK 清单》。

==============================================
法定情形下的共享
==============================================

  我们仅在下列法定情形下，可能依据法律法规或主管机关的合法要求共享必要的信息：

  1. 配合司法机关或行政机关依据法律法规的调查；
  2. 为维护社会公共利益或你个人的合法权益所必需；
  3. 法律法规规定的其他情形。

  在收到上述请求时，我们会审慎评估并要求接收方提供合法依据。

==============================================
跨境传输
==============================================

  无。

  本应用所有数据仅在设备本地处理，不存在跨境传输情形。
