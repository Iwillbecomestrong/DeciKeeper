二、收集哪些数据、为何收集、何时收集

  1. 本应用 **不在自有服务器上收集** 任何个人信息。
  2. 本应用的所有数据均保存在你的设备本地，未经你显式操作不会外发。
  3. 为了实现核心自律与保护功能，本应用会在设备本地保存以下信息：
     - 勿扰时段与应用时间窗的配置（SharedPreferences / 文件）；
     - 黑名单与全局参数配置；
     - 保护模块（防卸载、防关权限、闹钟防关机）的开关状态；
     - 应用崩溃与运行诊断日志（仅用于本地排错，30 天滚动覆盖）。
  4. 上述信息仅用于在你本机提供功能，**不涉及任何画像、定向推送、个性化推荐**。

三、调用了哪些系统权限

为实现下述功能，本应用会请求以下系统权限：

  - 使用情况访问（PACKAGE_USAGE_STATS）：识别当前前台应用是否在黑名单/时间窗外；
  - 悬浮窗（SYSTEM_ALERT_WINDOW）：在勿扰时段显示覆盖层、防止用户操作被拦截的应用；
  - 无障碍服务（BIND_ACCESSIBILITY_SERVICE）：防卸载、防关权限、防闹钟防关机等保护功能；
  - 设备管理器（BIND_DEVICE_ADMIN）：防卸载保护；
  - 通知相关权限（POST_NOTIFICATIONS / 锁屏显示 / 全屏通知）：闹钟挑战与心跳提示；
  - 开机自启动（RECEIVE_BOOT_COMPLETED）：保护开机后继续生效；
  - 精确闹钟（SCHEDULE_EXACT_ALARM / USE_EXACT_ALARM）：在指定时刻触发闹钟挑战；
  - 摄像头（CAMERA）：仅在用户主动使用"扫码导入设置"时短暂使用；
  - 振动（VIBRATE）：闹钟挑战与通知提示；
  - 唤醒锁（WAKE_LOCK）：保证闹钟挑战期间设备不会自动熄屏。

我们 **仅在实现对应功能所必需的范围内** 请求上述权限；用户可随时在系统设置中撤销。

四、使用了哪些第三方 SDK

  1. 当前本应用 **不接入任何会主动收集个人信息的第三方 SDK**（无统计、无广告、无推送、无账号）。
  2. 项目仅依赖少量开源 Android 基础库（Material Components、AppCompat、ConstraintLayout、WorkManager、ZXing、MPAndroidChart、GridLayout），它们均不涉及个人信息收集，详见《第三方 SDK 清单》。

五、数据与谁共享

  1. 原则上 **不与任何第三方共享** 你的个人信息。
  2. 仅有以下极少量例外：
     - 你主动使用"导出设置"或"发送日志"功能时，由你本人将 JSON / 日志文件分享给第三方（微信、邮件等）。此时数据由你主动提供，对应第三方按其自身政策处理。
     - 你使用"扫码导入设置"时，相机会读取你指向的二维码以解析本地配置，不上传到任何服务器。

六、保存地点和保存期限

  1. **保存地点**：全部保存在你设备本机的应用沙箱内（/data/data/com.decikeeper.app/）。
  2. **保存期限**：
     - 配置类数据：直到你卸载本应用或主动清除应用数据；
     - 诊断日志：滚动 30 天覆盖；
     - 同意状态：单独存于"privacy_consent_prefs"，**显式不参与云备份/换机迁移**（备份规则中已显式 exclude）。
  3. 卸载本应用后，所有上述数据将被系统一并清除。

七、用户如何查询、更正、删除、撤回同意

  1. **查询 / 更正**：你可以在应用内随时查看与修改勿扰时段、黑名单、参数配置等（设置页全部开放查看）。
  2. **删除**：
     - 在「设置 → 关于我们 → 账号注销入口」中查看删除说明；
     - 清除应用数据：系统设置 → 应用 → 决定守护 → 存储 → 清除数据；
     - 卸载应用：系统设置 → 应用 → 决定守护 → 卸载。
  3. **撤回同意**：
     - 在「设置 → 关于我们」中查看本协议与本政策；
     - 撤回方式：清除应用数据（会同时清除同意状态，下次启动会重新弹窗）。
  4. 如你对上述操作有疑问，可通过本政策"一、联系方式"中所列渠道与我们联系。

八、如何注销账号

本应用当前版本 **不提供账号体系**，不存在账号注销流程。

如你希望彻底删除本应用保存在本机的全部数据，请通过"清除应用数据"或"卸载应用"实现；详见本政策"七、用户如何查询、更正、删除、撤回同意"。

九、未成年人保护规则

  1. 本应用面向具备完全民事行为能力的成年人。
  2. 未成年人应在法定监护人指导下阅读本政策并决定是否使用本应用。
  3. 如你是未成年人，请在监护人陪同或指导下完成"同意"动作。
  4. 我们不会主动收集未成年人的个人信息；如发现未成年人未经监护人同意使用了涉及个人信息的功能，请通过"一、联系方式"告知我们，我们会协助处理。
